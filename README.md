# roche.pw

La boîte à outils d'Alexis. Site statique publié sur GitHub Pages.

- `site/` : tout ce qui est en ligne (`site/index.html` = accueil, un dossier par outil)
- `.github/workflows/pages.yml` : publie `site/` à chaque push sur `main`

Ajouter un outil : créer `site/nom-de-l-outil/index.html`, puis ajouter sa carte dans `site/index.html`.
